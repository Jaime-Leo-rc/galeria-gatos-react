# Galería de gatos

Galería de fotos de gatos hecha con React, Vite y CSS Grid. Cada foto tiene su propio botón de "Me gusta".

## Tecnologías

- React (componentes, props, `useState`, `useEffect`)
- Vite
- CSS Grid y Flexbox
- API pública de imágenes de gatos

## Cómo correrlo

1. Clona el repositorio
2. Instala las dependencias: `npm install`
3. Inicia el servidor: `npm run dev`
4. Abre http://localhost:5173

## Qué aprendí

proyecto con React: componentes reutilizables, estado con `useState` y consumo de una API con `fetch` y `async/await`.
